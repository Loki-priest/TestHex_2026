-суббота\вскр: анимации и эффекты ровно по рефу, логика канваса + таймер - 3ч
-пнд: полировка - 4ч
-вт: импорт плагинов, сделать билд, исправления скриптов (корутины, твины, компилятор), оптимизации (рендер, мс, память) - 5ч

-добавить звуки, больше эффектов, красочный гуи;
-оптимизация выделения памяти в скриптах;
-декомпозиция скриптов по SRP;
-проигрыш если все поля заполнили, но перекладываний не было.
